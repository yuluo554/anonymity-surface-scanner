# 02 · 架构与技术选型

> 上游：`plan/01-题目文档.md`（定稿）；数值口径与退出码唯一出处：`data/README.md` §四。
> 本文件只定义**结构**（分层 / 模块边界 / CLI 契约 / 错误分类 / 确定性设计 / 构建），**不重新定义任何数值口径**。

## 一、交付形态与选型

| 项 | 选择 | 理由 | 弃选 |
| --- | --- | --- | --- |
| 语言 | Python ≥ 3.8 | 单机、纯本地、零运行时依赖；3.8 是本机与 CI 的最宽下界 | — |
| 分发形态 | 控制台脚本 `anonymity-scanner`（`pip install .`） | 题目要求"安装后一条命令跑出结论" | 无 GUI / 无 Web（撞 arx 战场，见 `plan/00` 弃选项） |
| 第三方运行时依赖 | **零** | 安装后零网络、无 GPU；`pip install` 只装本包 | pandas（体积与 dtype 隐式转换会污染"不做隐式清洗"的纪律）、click/typer、rich |
| 表格读取 | 标准库 `csv`（`utf-8-sig`） | 只需 CSV/TSV；dtype 推断由本工具显式输出，不交给库 | 无 |
| 打包 | `setuptools` + `src/` 布局 | 与 `pip install .` / sdist 白名单验证路径一致 | poetry / hatch（引入锁文件与构建面差异，收益为零） |
| 测试期依赖 | `pytest`（`[dev]` extra） | 单一测试框架，CI 双矩阵直接跑 | unittest（断言表现力不足） |

## 二、分层

| 层 | 包 | 职责 | 禁止 |
| --- | --- | --- | --- |
| CLI 层 | `anonymity_scanner/cli.py` | 参数解析、命令分派、把结果/异常映射到退出码 | 不做统计、不读表 |
| 声明层 | `anonymity_scanner/declaration.py` | 读列角色声明 JSON、校验列名与角色枚举、产出不可变声明对象 | 不读表格数据 |
| I/O 层 | `anonymity_scanner/tableio.py` | CSV/TSV 读取、行号（1 起，不含表头）、缺失值判定、表宽校验 | 不做分组、不打分 |
| 计算层 | `anonymity_scanner/m1_candidates.py`（M1）<br>`anonymity_scanner/m2_classes.py`（M2）<br>`anonymity_scanner/m3_search.py`（M3）<br>`anonymity_scanner/m4_risk.py`（M4） | 纯函数：值 → 数值 / 行号 / 组合结论 | 不写盘、不读时钟、不读环境变量 |
| 判据层 | `anonymity_scanner/m5_gate.py` | 判据文件 → 阈值与策略 → 调用计算层 → 退出码结论 | 不自己实现 k/l/t（防第二套口径） |
| 输出层 | `anonymity_scanner/canonical.py`<br>`anonymity_scanner/report.py` | 确定性 JSON / 人读报告、路径相对化、浮点定点 | 不改变任何判定结果 |

依赖方向单向：`cli → m5_gate → {m2,m3,m4,m1} → tableio/declaration → canonical`。计算层不得反向 import CLI。

## 三、数据流（一条命令的完整路径）

```text
表 (CSV/TSV) ──┐
声明 (JSON)  ──┴─→ tableio.read_rows() ─→ declaration.validate() ─→ M1 schema/候选
                                                                  ─→ M2 等价类 (k/l/t + 违例行号)
                                                                  ─→ M3 组合搜索 (最小崩塌集 + 三态完整性)
                                                                  ─→ M4 逐记录风险 (三口径)
                                                                  ─→ M5 gate (判据文件 → JSON + 报告 + 退出码)
```

## 四、CLI 契约

```text
anonymity-scanner --version
anonymity-scanner schema --table <f> --decl <f> --out-dir <d> [--root <d>]
anonymity-scanner scan   --table <f> --decl <f> --missing-policy <drop|single-column|separate-class> \
                         --k <int> [--l <int>] [--t <float>] --out-dir <d> [--root <d>]
anonymity-scanner search --table <f> --decl <f> --missing-policy <...> --k <int> \
                         --budget <int> [--require-exhaustive] --out-dir <d> [--root <d>]
anonymity-scanner risk   --table <f> --decl <f> --missing-policy <...> \
                         --attacker <prosecutor|journalist|marketer> --out-dir <d> [--root <d>]
anonymity-scanner gate   --criteria <f> --out-dir <d> [--root <d>]
```

契约要点（全部锁进测试）：

1. `--missing-policy` **无默认值**：`scan/search/risk/gate` 缺它即 `2`（判据文件里给了即可）。
2. `--root` 是"报告中路径的相对化基准"；未给时取当前工作目录。报告中**不出现绝对路径**。
3. `--out-dir` 下的产物名固定（`schema.json` / `scan.json` / `search.json` / `risk.json` / `gate.json` + `gate.md`）。
4. 未知子命令、缺必填参数 → argparse 退出码 `2`（与 `data/README.md` §4.6 的"无法裁决"同码，不与"违例"混淆）。
5. 未实现模块 → 打印 `MODULE_NOT_READY` + 计划落点（`plan/03 §Mx`），退出码 `2`，**不产出半份结果、不返回 0**。

## 五、错误分类与退出码

`data/README.md` §4.6 是退出码唯一出处；本文件只写"哪类错误映射到哪一码"，代码里只允许**一个**映射函数
（`anonymity_scanner/exit_codes.py: map_outcome`）。

| 异常 / 结果 | 语义 | 退出码 |
| --- | --- | --- |
| `Outcome.PASS` | 全部声明阈值满足且完整性未被裁剪 | `0` |
| `Outcome.VIOLATION` | 存在违例 | `1` |
| `InputError`（表缺列、宽度不符、编码错误、空文件） | 输入无效 | `2` |
| `DeclarationError`（角色不在枚举、声明了不存在的列、日期精度缺失） | 声明无效 | `2` |
| `CriteriaError`（判据缺项、未知字段、缺失策略缺失） | 无法裁决 | `2` |
| `ModuleNotReady`（M1–M5 未实现） | 无法裁决 | `2` |
| 未捕获异常 | 内部错误（**不得**退化为 `0`） | `2` |

## 六、确定性设计（K 编号见 `plan/03` §K）

| 关注点 | 做法 |
| --- | --- |
| 序列化 | 单一入口 `canonical.dumps()`：`sort_keys=True`、`ensure_ascii=False`、`indent=2`、`separators=(",", ": ")`、结尾一个 LF |
| 写盘 | `canonical.write_text_atomic()`：先写临时文件再 `os.replace`；强制 `newline="\n"` |
| 浮点 | 全部 `round(x, 6)` + `ROUND_HALF_EVEN`；JSON 里不出现 `NaN` / `Infinity`（`allow_nan=False`） |
| 行号 | 输入文件数据行序号，1 起，不含表头；分组内行号升序 |
| 排序 | 等价类键按规范化字符串的 Unicode 码位序；列按 CSV 表头顺序；候选按 `(-qi_score, name)` |
| 禁用项 | 时钟、主机名、随机数、`set` 迭代序、绝对路径、环境变量影响结论 |
| 验证 | 每条命令双跑逐字节一致（测试断言），产物里不含 `datetime` / 主机名（测试扫描） |

## 七、构建与打包

- `pyproject.toml`（PEP 621）：`name = "anonymity-scanner"`、`requires-python = ">=3.8"`、
  `dependencies = []`、`[project.optional-dependencies] dev = ["pytest>=7"]`、
  `[project.scripts] anonymity-scanner = "anonymity_scanner.cli:main"`。
- 版本号**单一来源** = `anonymity_scanner/__init__.py:__version__`；`pyproject.toml` 用
  `dynamic = ["version"]` + `[tool.setuptools.dynamic] version = {attr = "anonymity_scanner.__version__"}`
  ——避免两处手抄（同族纪律：版本只有一处可编辑副本）。
- `MANIFEST.in` 白名单纳入 `data/README.md`、`plan/00`–`06`、`AGENTS.md`、`LICENSE`
  （= 让 sdist 自足；验证方式见 `plan/05` M6 的"源码包自足"门）。
- `src/` 布局：`[tool.setuptools.packages.find] where = ["src"]`。
- 构建**只在 `git archive <tag>` 导出的干净目录里做**（产物同源判据，见 `plan/05` M6）。

| 面 | 内容 |

| 单元 | 退出码映射、序列化、表读取、声明校验、M1 统计的纯函数性 |
