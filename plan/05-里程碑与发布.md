## 五、发布路径（M6）

1. `git tag -a v0.1.0`（annotated，tagger 用 noreply 邮箱）。
2. **在 `git archive <tag>` 导出的干净目录里**构建 sdist。
3. `gh release create v0.1.0 dist/anonymity_scanner-0.1.0.tar.gz --notes-file <发布正文>`。
4. 回下载 → `sha256sum -c` + 与 tag 重打包 `cmp`。
5. `plan/RELEASE-M6.md`：**tag 前**入库两栏骨架（§一 tag 前事实 / §二 tag 后追加），字面 digest 只写进 Release 正文或 tag 后提交。
6. 首推 → 等 CI 绿 → 据实补记 run 与结论（历史措辞不改，补记是追加事实）。
