# 00 · README 总览 — 10-20-anonymity-surface-scanner（匿名性攻击面搜索器）

> 方法论：`ai-tool-project-sprint`（装订 2026-10-20）｜布局门：`py -3.12 tools/check_sprint_layout.py`｜续接对话第一件事 = 跑它

- **项目**：匿名性攻击面搜索器（Anonymity Surface Scanner）——纯本地 Python CLI
- **性质**：不参赛项目题 · 发布 GitHub **公开仓库** · 署名 `yuluo554`
- **版本**：v1（2026-10-20 定稿；需求侧、竞品与开源检索基准日 **2026-10-20**）；当前提交 = M3 收尾（组合搜索落地）
- **当前状态**：**M3 完成**（组合攻击面搜索：反单调剪枝、预算、最小崩塌集、完整性三态与崩塌曲线；`search` 已产出 `search.json` 并返回真实退出码）。M0–M1 已交付骨架与独立真值夹具，M2 已交付等价类引擎；计算实现 M1（`schema`）、M4（`risk`）、M5（`gate`）仍未落地，三条子命令一律 `MODULE_NOT_READY` + 退出码 `2`（fail-closed，不伪造结果）。
- **一句话定位**：k/l/t 公式是商品，**没人回答"哪几列组合会让 k 崩塌"**——本工具输入一张表 + 列角色声明，输出最小 k、**最小崩塌集**、每处违例的等价类与行号清单（可手算复核）、以及可挂 CI 的 gate 结论。搜索层是护城河，不是公式层。
- **交付形态**：**纯本地 Python CLI**（唯一形态，不设备选）。无 GPU、无云、无网络调用、无需真实敏感数据。
- **撞域切割**：同系列既有题材分别在**制度与流程层**（产检查清单、评制度）与**文本条款层**（读文档、标风险条款）作业；本题是**数据层的可计算量**——输入数据行，产出数值、行号与列组合（方向级描述，具体领域按品牌隔离纪律不展开）。

## 二、决策记录

> **D1–D4 是定位生死线，任何里程碑不得削弱。**

| 编号 | 日期 | 决策 | 理由 / 弃选 |
| --- | --- | --- | --- |
| **D1** | 2026-10-20 | **只押"组合搜索 + 可复算证书"，公式层照抄公开定义、不做"更好的 k/l/t"** | arx 738★ / sdcMicro 95★ / pycanon 54★ 已把公式层做完且免费。做"更准的 k"没有入口；做"哪几列组合会让 k 崩塌"没有竞争者。 |
| **D2** | 2026-10-20 | **QI 候选不猜列名**：候选分只由基数与唯一值率给出，且两个输入统计量必须同时出现在报告里；`direct-identifier` 默认不参与 k/l/t 计算 | piiscope 用 `_QI_NAME_HINTS` 硬编码 age/zip/sex，2★ 且月下载 58——"猜列名"是它的失败点。角色由人声明（"未声明即不参与"），工具只给可解释候选。 |
| **D3** | 2026-10-20 | **完整性三态必须显式**：`已穷尽` / `被预算截断` / `单调性不适用`，三者不得合并 | 剪枝只在"固定行集 + 只分组"下成立（见 `plan/01` §M3）。把"没算"说成"没问题"是本类工具最危险的失败模式；fail-closed 必须贯彻到完整性声明。 |
| **D4** | 2026-10-20 | **缺失值语义显式三选一**（`drop` / `single-column` / `separate-class`），不指定即报错，不猜 | sdcMicro #363 就是"缺失值下 l 值算错"。把缺失值处理做成隐式默认，等价于让结果不可复算。 |
| D5 | 2026-10-20 | 阈值是**政策输入**，写在判据文件里；退出码 `0/1/2` 由 `data/README.md` §四单点定义 | 工具不得把阈值写进代码；"算不出来"必须是 `2`，绝不能退化为 `0`。 |
| D6 | 2026-10-20 | **单表、单机、无网络**；不做 record linkage、不做多表连接攻击 | 多表链接需要外部辅助数据，会逼用户交出真实敏感数据，撞隐私红线。 |
| D7 | 2026-10-20 | 报告**不含绝对路径与时间戳**（路径以 `--root` 相对化） | 报告要能直接贴进 CI 日志与 issue；绝对路径会泄露本机目录结构，时间戳会破坏逐字节可复算。 |
| D8 | 2026-10-20 | 真值由**夹具生成器**写入，搜索器不得自证 | 自证的真值等于没有真值。生成器与判定式独立实现、不 import 生产模块。 |
| D9 | 2026-10-20 | 品牌隔离：命名围绕"扫描器 / 攻击面 / 等价类 / 崩塌集"；文档不提名姊妹项目 | 与系列内"合规审计""政策条款审查"两类产物在受众心智上必须分开。 |

### 弃选项（候选方向，均已否决）

| 弃选项 | 弃因 |
