## 二、真值结构

每个夹具目录一份 `truth.json`（键序固定，生成器写）：

```json
{
  "fixture": "small",
  "seed": 20261020,
  "rows": 60,
  "columns": ["age", "zip", "dob", "sex", "disease", "name", "phone", "note"],
  "planted": [
    {"kind": "singleton_classes", "columns": ["zip", "dob"], "expected_count": 3,
     "class_keys": ["zip=zip-00009|dob=1999-08", "..."], "row_numbers": [58, 59, 60]}
  ],
  "minimal_collapse_sets": [["age"], ["sex"]],
  "collapse_sets_status": "non-exhaustive",
  "empty_set_witness": false,
  "k_by_columns": {"[]": 56, "[\"age\"]": 11, "[\"age\",\"zip\"]": 1},
  "violations": [
    {"key": "zip=zip-00001|dob=1990-01|age=20|sex=F", "count": 1, "row_numbers": [7]}
  ],
  "missing_rows": [5, 12, 31, 44],
  "unique_records": [1, 2, 3]
}
```

> 上例是**结构示意**（`...` 与部分行号非真实值）。权威数据以 `data/fixtures/*/truth.json` 为准，
> 结构说明见 `data/fixtures/README.md`。除上面这些契约键外，真值还带 `k_l_t` / `by_policy` /
> `search` / `search_scenarios` / `meta` / `declaration` / `missing_cells` 等下钻块，供 M2–M5 逐项对照。

**真值纪律**（`data/README.md` §三 + `plan/03` K10）
1. 期望值由生成器的**独立判定式**写出：生成器自己持有"我植入了什么"的知识，并从**已生成的行**用一段
   **不复用生产模块**的朴素 oracle 实现复算一遍（`tools/fixture_oracle.py`，见 §六）。
   两处判据都跑，结果不一致 → 生成器直接失败（`build_truth` 里逐项 `assert`）。
2. 真值只存**输入与期望**，不存 `observed_*` 一类字段。
3. 固定种子 + 固定参数 → 表与真值逐字节相同；生成器的 `--check` 通路重生成到临时目录后逐字节比对（命令见 §六）。
4. 植入项要**可检出**：生成期断言植入项的**精确**形态——单例类数 `== 3`、单列 k `== 3`、
   `l == 1` 的那一类的行号清单逐项相等（不是"我以为是单例"，也不是"大约"）。
5. 缺失位置显式登记（`missing_rows` + 逐格 `missing_cells`），三策略的期望结果分别给出；
   无缺失的夹具后两种策略写 `{"same_as": "drop"}`（口径相同就说相同，不抄三遍）。

## 三、植入纪律

| 夹具 | 植入什么 | 生成期断言（实测见 `data/fixtures/*/truth.json` 的 `planted`） |
| --- | --- | --- |
| `tiny` | 单列 `age` 每个取值出现 3 次（k=3 恰好达标）；`age`+`zip` 交叉后全为单例 | `k({age}) == 3`；`k({age,zip}) == 1` |
| `small` | `zip+dob` 组合出现 3 个单例类；最大类内 `sex` 全同（l=1 用例）；4 行缺失覆盖 4 种 token | 单例类数 `== 3` 且行号 `== [58,59,60]`；该类的 `l == 1`；含缺失行 `== [5,12,31,44]` |
| `prune` | 三列单列即崩塌（`zip` 全不重复 k=1；`dob` 每值 2 行 k=2；`sex` 含 2 行稀有值 k=2）→ 其超集全部被剪掉；安全对照列 `age`(k=30) / `region`(k=100) | 五个单列 k 逐一 `==` 期望值；无缺失 → 三种策略下都保留全部 300 行 |
| `budget` | 10 个候选列，子集空间 1023 ≫ 预算 40；每个单列 k ≥ 阈值（单列阶段不剪枝） | 子集空间 > 预算；10 个单列 k 全部 ≥ 阈值；`completeness == "budget-truncated"` |

所有夹具的取值均为**明显虚构**（`alice-001`、`zip-00042` 一类），不含任何真实姓名/证件号/电话号段。

**缺缺失值的夹具**（`tiny` / `prune` / `budget`）不是遗漏：它们分别承担"单调性前提成立时能穷尽"
的对照，`small` 才是缺失语义与 `monotonicity-not-applicable` 的用例载体。三态里每一态都要有夹具能触发它。

## 六、生成器与冻结产物

**真实路径（M1 落地后回填）**

| 件 | 路径 | 说明 |
| --- | --- | --- |
| 生成器 | `tools/gen_fixtures.py` | 固定种子（`20261020`）+ 自研 splitmix64；**禁 `random`**；不 import 生产模块 |
| 独立 oracle | `tools/fixture_oracle.py` | 朴素复算（每次从头分组、`Fraction` 算总变差）；生成器单向 import 它，它**不** import 生成器 |
| 验收测试 | `tests/test_fixtures.py` | AST 守门（互不 import / 不碰生产包 / 无 `random`）+ 真值纪律 + 逐字节 + `--only` + sha256 |
| Adult 基线 | `tools/adult_baseline.py` | 只读本地、不联网（AST 断言无网络模块）；未取得文件时退出码 `3` 并如实标注 |

| 命令 | 作用 |
| --- | --- |
| `py -3.12 tools/gen_fixtures.py` | 全集生成：四组表 + 真值 + `manifest.json` |
| `py -3.12 tools/gen_fixtures.py --check` | 重生成到临时目录并与入仓真值逐字节比对（干净 clone 里同样成立） |
| `py -3.12 tools/gen_fixtures.py --only tiny` | 局部生成；**绝不改写全集清单**（`manifest.json` 只在全集运行时写，有专项测试） |
| `py -3.12 tools/adult_baseline.py --table <adult.data>` | Adult 读入基线：报行数 / 列数 / 含空或 `?` 的列 |
| `py -3.12 -m pytest tests/test_fixtures.py` | M1 的 DoD 全部断言 |

`data/fixtures/manifest.json` 登记：生成器 sha256、oracle sha256、每份真值 sha256、种子、参数。
生成器或 oracle 改动而未重生成 → `manifest.json` 的摘要对不上 → 测试红（把"靠记得"变成显式红灯）。
