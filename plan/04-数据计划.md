## 二、真值结构

每个夹具目录一份 `truth.json`（键序固定，生成器写）：

```json
{
  "fixture": "small",
  "seed": 20261020,
  "rows": 60,
  "columns": ["age", "zip", "dob", "sex", "disease", "name", "phone", "note"],
  "planted": [
    {"kind": "singleton_class", "columns": ["zip", "dob"], "row_numbers": [7, 31],
     "expected_class_key": "zip=..., dob=...", "expected_count": 1}
  ],
  "minimal_collapse_sets": [["age", "zip", "dob"]],
  "k_by_columns": {"{\"age\"}": 12, "{\"age\",\"zip\",\"dob\"}": 1},
  "violations": [
    {"key": "zip=...|dob=...", "count": 1, "row_numbers": [7]}
  ],
  "missing_rows": [5, 12, 44],
  "unique_records": [7]
}
```

**真值纪律**（`data/README.md` §三 + `plan/03` K10）
1. 期望值由生成器的**独立判定式**写出：生成器自己持有"我植入了什么"的知识，并从**已生成的行**用一段
   **不复用生产模块**的朴素 oracle 实现复算一遍（M1 交付，见 §六）。两条路径不一致 → 生成器直接失败。
2. 真值只存**输入与期望**，不存 `observed_*` 一类字段。
3. 固定种子 + 固定参数 → 表与真值逐字节相同；生成器的 `--check` 通路重生成到临时目录后逐字节比对（命令见 §六）。
4. 植入项要**可检出**：生成期断言"植入的类大小 ≤ 阈值"，且实例数 ≥ 1（不是"我以为是单例"）。
5. 缺失位置显式登记（`missing_rows`），三策略的期望结果分别给出。

## 三、植入纪律

| 夹具 | 植入什么 | 生成期断言 |
| --- | --- | --- |
| `tiny` | 单列 `age` 每个取值出现 ≥ 3 次（k=3 通过） | 单列类大小最小值 == 期望值 |
| `small` | `zip+dob` 组合出现 3 个单例类；`sex` 在某个类内全同（l=1 用例） | 单例类数 == 3；该类的 l == 1 |
| `prune` | 两个低基数列（`sex`/`region`）单列远低于阈值 → 其超集全部应被剪掉 | `k({sex}) < threshold` 且 `k({sex, x}) < threshold` |
| `budget` | 10 个候选列，组合数 > 预算 | 未剪枝子集数 > `budget` |

所有夹具的取值均为**明显虚构**（`alice-001`、`zip-00042` 一类），不含任何真实姓名/证件号/电话号段。

## 四、Adult 演示数据计划

- 来源：UCI Machine Learning Repository, Census Income（`adult.data` / `adult.names`），公开可下载。
- **不入库**：脚本只读本地文件；`examples/adult/README.md` 给下载步骤，并说明"本仓库不代下载"。
- 演示脚本：`examples/adult/run.sh` 调 `anonymity-scanner gate --criteria examples/adult/criteria.json --out-dir out/adult`。
- 期望输出摘要（`EXPECTED.md`）：**M5 实跑后回填**，只写"命令 + 退出码 + 关键数字"，不预写任何 k 值。
- 若 M6 前无法稳定下载：如实标注"演示未实跑"，并在 `plan/06` 缺口表登记（**不得**编造数字）。

## 六、生成器与冻结产物
| 命令（M1 交付后可用） | 作用 |
| --- | --- |
| `anonymity-scanner` 之外的生成入口 | 全集生成：表 + 真值 + `manifest.json` |
| 同上 `--check` | 重生成到临时目录并与入仓真值逐字节比对 |
| 同上 `--only <suite>` | 局部生成；**绝不改写全集清单**（`manifest.json` 只在全集运行时写） |

`data/fixtures/manifest.json` 登记：生成器 sha256、每份真值 sha256、种子、参数。
生成器改动而未重生成 → `--check` 红（把"靠记得"变成显式红灯）。
